# Algoritmos from Scratch

Repositorio educativo con notebooks de Jupyter sobre algoritmos, fundamentos de ciencias de la computación y temas avanzados relacionados.

## Contenido del repositorio

- `AlgorithmicComplexity.ipynb`: análisis de complejidad temporal/espacial y notación asintótica.
- `CSFoundations.ipynb`: conceptos base de ciencias de la computación.
- `SearchAlgorithms.ipynb`: algoritmos de búsqueda clásicos.
- `SortingAlgorithms.ipynb`: algoritmos de ordenamiento y comparativas.
- `Graphs.ipynb`: estructuras y algoritmos de grafos.
- `OptimizationAlgorithms.ipynb`: técnicas y enfoques de optimización.
- `CompressionAlgorithms.ipynb`: fundamentos de compresión de datos.
- `SyntheticDataGenerativeModels.ipynb`: introducción a datos sintéticos y modelos generativos.
- `QuantumComputing.ipynb`: conceptos iniciales y experimentos de computación cuántica.

## Requisitos

- Python 3.10+ (recomendado)
- Jupyter Notebook o JupyterLab

Dependencias sugeridas (según el contenido de cada notebook):

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn networkx
```

> Nota: algunos notebooks pueden requerir librerías adicionales según los experimentos incluidos.

## Cómo usar

1. Clona este repositorio:

```bash
git clone <URL_DEL_REPO>
cd algoritmos-from-scratch
```

2. Inicia Jupyter:

```bash
jupyter notebook
```

3. Abre el notebook que quieras explorar y ejecuta las celdas en orden.

## Objetivo

Este proyecto busca servir como material práctico para:

- estudiar algoritmos desde cero,
- comparar enfoques y complejidades,
- experimentar con implementaciones paso a paso.
